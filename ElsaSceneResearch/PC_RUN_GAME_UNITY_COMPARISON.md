## What is visible

- Both show a recognizable run cycle with a broadly similar long, triangular trailing dress silhouette during the extended stride.
- Angular dress folds and exposed legs also appear in the original game. A sharp fold alone does not establish an importer or weight error.
- The bent-knee samples show different hem openings, hand positions and upper-body silhouettes. These differences are visible, but their cause cannot be isolated from these unmatched views.
- Movie 027 shows only a modest posture change from adding static run lean. It does not establish that the remaining garment behavior has been corrected.

## Limits and next test

No numerical joint-angle, foot-contact or skinning parity is established by this sheet. Do not tune weights based on it alone. The next useful test is a controlled game capture with a near-side camera and a complete steady run cycle, followed by contact-phase alignment against Unity. Compare the feet and pelvis first, then torso and arms, then the dress. If the body matches while the garment differs at aligned phases, inspect garment driver transforms and skinning separately. If the body differs, check source layers and graph evaluation before changing the mesh.

The existing native curve and blend fixture validations remain separate evidence: they validate bounded computations, not full actor-level playback parity.
